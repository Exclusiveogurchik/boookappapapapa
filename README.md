# BookApp — читалка PDF-книг 📚

Офлайн-читалка PDF с удобным reflow-режимом, заметками и статистикой чтения.
**Все данные хранятся локально в браузере (IndexedDB) — никакого бэкенда.**

## Стек

- **React 18 + TypeScript + Vite**
- **Tailwind CSS** (темы через CSS-переменные)
- **pdf.js** (`pdfjs-dist`) — парсинг и отрисовка PDF
- **Dexie** (IndexedDB) — книги, текст, заметки, статистика
- **PWA** — офлайн-режим (service worker, автообновление)
- Web Worker — извлечение текста не блокирует интерфейс

## Возможности

| Раздел | Что умеет |
|---|---|
| 📚 Библиотека | Импорт PDF (drag & drop, несколько файлов, прогресс), обложка из первой страницы, метаданные, статусы, полки, теги, поиск + полнотекстовый поиск, сортировка, удаление/редактирование |
| 📖 Читалка | Два режима: «Удобное чтение» (reflow с настройками шрифта/полей/пагинации) и «Оригинал» (зум, pinch, двойной тап). Темы: светлая/сепия/тёмная/AMOLED/авто. Режим фокуса, линейка чтения, оглавление (outline PDF или авто-главы), поиск по книге, ползунок перехода |
| 📝 Заметки | Автосохранение позиции, закладки, выделения 4 цветами с заметками, экспорт в Markdown, бэкап/восстановление JSON |
| 🎓 Изучение | Тап по слову → определение + перевод, словарь с карточками (SM-2), озвучка Web Speech API с подсветкой слов и таймером сна |
| 📈 Статистика | Активное время чтения, страницы/слова в день, streak, цель дня, скорость чтения, оценка «осталось ~N минут», графики за неделю/месяц |
| 💬 Цитаты | Генерация картинок-цитат в 5 стилях, скачивание / Web Share |
| ✨ ИИ (опционально) | «Кратко о главе» и «Объясни проще» через Anthropic API (ключ хранится локально) |

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка + PWA
npm run preview
```

Для быстрого теста в `samples/` лежит небольшой `sample-book.pdf`.

## Горячие клавиши

`←`/`→` — страницы · `F` — фокус · `/` — поиск · `B` — закладка · `T` — тема · `R` — линейка · `O` — режим · `Esc` — закрыть

## Структура кода

```
src/
  db/          # схема Dexie, репозитории, типы
  workers/     # Web Worker извлечения текста + алгоритм reflow
  features/    # library / reader / notes / study / stats / quotes / ai / settings
  shared/      # UI-кит, хуки (настройки, тема, тосты, хоткеи), утилиты
  i18n/        # словари ru/en
```
